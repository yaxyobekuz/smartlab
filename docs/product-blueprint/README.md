## The one-paragraph thesis

Smart Lab is a collection of excellent **sandboxes**. Sandboxes churn (PhET's problem). The highest-leverage work is **not more demos** — it's the four systems that turn demos into learning, in this order:

1. **Lab Notebook** — persist any simulator's state (prereq for everything)
2. **Quest Engine** — JSON win-conditions checked against live sim state (the missing *"why"*)
3. **Socratic AI** — reads the live scene, gives *hints not answers* (you already have the Gemini pipeline)
4. **Mastery progression** — XP/streaks/achievements tied to *discovery & manipulation*, never logins
